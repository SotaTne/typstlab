# Agent Instructions

- Use the `typstlab` MCP server for this project.
- Start with MCP `status` to understand papers, paths, and outputs.
- Use data from `status` instead of guessing project structure.
- Use MCP `build_and_render` to build page images and return the images to the agent, not PDFs.
- Project config: `typstlab.toml`.
- Typst docs: `.typstlab/typst_docs`.
